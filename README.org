* STM32 PCB Design
** Overview
This is my first PCB design project. It is basically a clone of the board designed by Philip Salmony, part of his YouTube video tutorial [[https://youtu.be/aVUqaB0IMh4?si=W57RVr_CsgqvWgg2][KiCAD STM32 PCB Design Full Tutorial - Phil's Lab #65]]. I haven't experimented with the design yet, since I am just getting started but I will definitely add some features in the future. I am incredibly thankful to him. The design contains a STM32F103C8T6 microcotroller and a AMS1117-3.3 linar power regulator, it has three communication protocol male connectors namely USART & I2C along with Serial Wire Debuging. The pinout was done by Philip using STM32Cube IDE. The only thing that I didn't follow from the tutorial was the placment and routing, I did it by myself so that I could learn from my mistakes.
