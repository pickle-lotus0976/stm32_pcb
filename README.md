# STM32 PCB Design

## Overview

This is my first PCB design project. It is essentially a clone of the board designed by Philip Salmony, that was featured in his YouTube video tutorial: [KiCad STM32 PCB Design Full Tutorial - Phil's Lab #65](https://youtu.be/aVUqaB0IMh4?si=W57RVr_CsgqvWgg2). I have not experimented with the design yet, since I am just getting started, but I will definitely add more features in the future using this design as tha starting point. I am incredibly thankful to him for the tutorial. The design contains an **STM32F103C8T6 microcontroller** and an **AMS1117-3.3 linear power regulator**. It has three communication-protocol connectorsnamely USART, I²C & Serial Wire Debugging (SWD). The pinout was created by Philip using STM32CubeIDE. The only part of the tutorial I did not follow was the placement and routing. I completed those myself so that I could learn from my mistakes.
